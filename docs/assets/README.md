# Project artwork and screenshots

The WAN Observer symbol and composition are original artwork created for this project. Copyright © 2026 Danijel Dedic, under the repository’s MIT license. The wordmark uses outlined Manrope lettering. Its font license is retained in MANROPE-OFL.txt; no runtime font or external resource is required by the SVGs.

Screenshots were captured from WAN Observer running on a GL.iNet Flint 2 with firmware 4.11.0 on 11 November 2026, with the owner's explicit approval for public use. They show the actual native dashboard and settings, with no demo overlays. Only the application area was retained; browser tabs, address bar and bookmarks are excluded. Displayed measurement values were not altered.

Do not attach personal or customer screenshots without authorization. Keep credentials and network identifiers out of public captures.
