# Project artwork and screenshots

The WAN Observer symbol and composition are original artwork created for this project. Copyright © 2026 Danijel Dedic, under the repository’s MIT license. The wordmark uses outlined Manrope lettering. Its font license is retained in MANROPE-OFL.txt; no runtime font or external resource is required by the SVGs.

Screenshots show the production UI bundle with synthetic measurements in a local review harness. The GL.iNet components in that harness are approximations. They illustrate features and contain no operational network data. Actual package installation and native rendering were separately checked on a Flint 2 running firmware 4.11.0.

Keep screenshots clearly labelled as demo data. Do not replace them with personal or customer network history.
